# Sidebar brand icons

NVIDIA, YouTube, Instagram and TikTok path data were obtained from the Simple Icons repository on 2026-10-17:
https://github.com/simple-icons/simple-icons/tree/develop/icons

The upstream CC0 license is preserved in LICENSE.md. Brand names and marks remain their owners' trademarks. Icons identify the detected GPU vendor and the supported export targets; no affiliation is claimed. WPF geometries are derived from these local SVG files in BrandResources.xaml. No network access is needed at runtime.
